# Portfolio Website

## Overview

This project is a personal portfolio website created using HTML, CSS, and JavaScript. The website displays information about the student, featured resources, projects, and contact information.

The portfolio also includes:

- Dark mode functionality
- Session storage for project data
- Dynamic project rendering using JavaScript
- A custom welcome modal
- Tooltips for interactive elements

---

## Languages and Libraries Used

- HTML5
- CSS3
- JavaScript

No external libraries or frameworks were used.

---

## Dependencies

This project does not require any external dependencies.

---

## Features

- Responsive webpage layout
- Dynamic project cards generated from JavaScript objects
- Session storage using JSON.stringify() and JSON.parse()
- Persistent dark mode using localStorage
- Interactive modal and tooltip components

---

## How to Run the Project

1. Download the project files.
2. Open the project folder.
3. Double-click the HTML file or open it in a web browser.
